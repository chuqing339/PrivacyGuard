# FJ HostsBlock 关键域名白名单
#
# 这里的域名【永不屏蔽】：不会写进 hosts 挡表；解析出的 IP 也会在 IP 层放行（链首 RETURN）。
# 用途：保护 LSPosed 在线更新、GitHub、系统更新、小米账号等关键功能，
#       避免它们的 IP 与广告域名的 IP 撞车时被连带 REJECT。
#
# 格式：一行一个域名；# 加注释；分节用 [名字] 行（会被忽略）。
# 想保护自己的域名，直接在下面追加一行即可。
